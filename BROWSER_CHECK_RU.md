# Повторный браузерный прогон

Проверена именно ASH_IRON_ITERATION_1_0_1 после исправления фокуса управления. Фактические результаты — browser-check.json. Chromium запускался через Playwright в Linux с ANGLE SwiftShader. Это настоящий браузерный запуск и компиляция WebGL2-шейдеров, но на программном рендере, не на Intel UHD пользователя.

15 проверок прошли: загрузка runtime, WebGL2, пауза, WASD сразу после Resume, стрелки после Reset, отключённые способности, REFERENCE и WEBGL2 с непустой сценой, движение после переключения backend, отчёт, сброс на паузе, панель без F2, коллизии модуля в браузере, автономный file:// запуск без HTTP-запросов, управление и скачивание отчёта из CONTROL.html. Ошибок JavaScript нет.

PNG reference-frame.png и webgl2-frame.png сохранены на одинаковом замороженном кадре после сброса. Они предназначены для ручного визуального сравнения. Растр букв WebGL2 отличается от нативного субпиксельного текста Canvas; художественное совпадение пользователем ещё не утверждено.

Повторение автоматизации: установите Python, затем выполните `python -m pip install -r tools/browser-requirements.txt`, `python -m playwright install chromium`, `python tools/browser-check.py`. Нужен Node.js для сервера. Для первого получения Python-пакета и браузера потребуется интернет. Сама игра не требует Python и не требует скачиваний.

Скрипт повторения собран из функций, исполненных в этом прогоне; его синтаксис проверен. Результаты JSON относятся к исполнению этих функций в данной среде. Производительность SwiftShader не означает FPS на вашем ноутбуке. Проверки Vite и Windows-батников в этот прогон не входят.
