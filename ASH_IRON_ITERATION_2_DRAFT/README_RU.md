# ASH / IRON — ITERATION 2 / COMBAT CORE DRAFT

Промежуточный результат начала второй итерации. Это исходники и тесты боевого слоя, НЕ готовая версия игры и НЕ ZIP для замены первой итерации.

В пакет входят TypeScript-исходники, скомпилированные ES-модули и тесты. Тут намеренно нет START.bat или HTML, изображающего якобы законченную интеграцию.

## Что уже работает на уровне логики

Лёгкие/тяжёлые атаки, очередь отдельных нажатий и три позиции серии; урон не чаще одного раза цели за удар; углы/дальность и блокировка препятствиями; лунж с проверкой столкновений; один противник с телеграфом и восстановлением; контактные искры и веер; жизнь-лампа, победа, смерть и сброс комнаты; интерполируемые снимки состояния.

В адаптере используются клипы и emit оригинального IronPilgrim. Новый герой не придумывался. Сам vendor/hero.js должен поступать из первой итерации, он не изменяется.

## Проверка

Node.js 20.19+:

- node --test — тесты уже скомпилированного кода без установки зависимостей.
- npm install — инструменты разработки, нужен интернет.
- npm run typecheck — строгая типизация.
- npm test — пересборка runtime и тесты.

В этой среде реально выполнены TypeScript 5.8.2 strict (9 файлов, 0 диагностик), emit JavaScript и 29 тестов Node. Браузерного запуска, проверки рендера, меню и FPS НЕТ — они ещё не интегрированы.

Полный порядок подключения: docs/INTEGRATION_RU.md. Фактический статус: BUILD_INFO.json. Параметры спорных решений отделены в DRAFT_RULES.

Это не замена обещанного полного ZIP и автономного HTML второй итерации. Они появятся только после подключения и проверки этого слоя в реальной сцене.
