# Gallery obstacle collision draft

Connects the complete scene.getColliders() list to the walking player, independent of render-camera selection. Existing gameplay/combat collision code is not modified. Collider polygons are copied and indexed in an eight-unit XY grid. Actor collision uses a circle (default radius .24) and fixed ground-body height (default 1.8); shapes wholly overhead/below the floor do not block. Only authored contours are used, not exhibit reservation boxes.

Movement uses short substeps and axis-wise safe-prefix searches to prevent thin-wall tunnelling and permit wall sliding. Motion velocity, travelled distance, animation and camera update from the resolved position. An occupied spawn is rejected, not silently teleported. Low obstacles remain blocking; no climbing, stairs, ducking, damage, destruction or extra interactions are added. Doors remain physically closed until the separate door-state integration. The spatial index is static for this stage; dynamic door changes will require rebuilding/updating it.
