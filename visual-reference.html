Настройки просмотра — вне игрового HUD

WASD / стрелки / ЛКМ по полу — движение. Пробел / ПКМ — удар. E — веер искр. Q — лечение. F — печать / свечи / врата. Esc — меню. HUD содержит только здоровье и заряд лампы. Лампа медленно тлеет; её можно подпитать у свечей или печати. Веер искр не расходует лампу.

Авторский орнамент по направлению приложенного референса: чёрный фон, серое символьное железо, тяжёлые буквы. Без чужих логотипов и надписей. Игровая сцена сохраняет тусклый янтарный цвет. Прототип без звука; localStorage используется при разрешении браузера.
