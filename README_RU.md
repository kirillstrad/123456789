# ASH / IRON — Iteration 2 / Canvas2D

Запуск: распаковать ZIP и открыть PLAY.html или START.bat. Для серверного запуска: Node.js 22 и npm start.

## Структура
- src/ — исходники: combat/, game/, animation/, core/, render/, ui/, app/.
- public/vendor/hero.js — неизменённая модель героя.
- runtime/ — готовые модули; генерируются сборщиком, не редактировать.
- tools/ — сборка, браузерная проверка, упаковка.
- tests/ — тесты боевого ядра и интеграционные проверки.
- docs/ — отчёты именно текущего запуска проверок.
- reference/visual-reference.html — исходный визуальный ориентир; не запускать вместо PLAY.html.
- .github/workflows/iteration-2-canvas2d.yml — сборка и ZIP в GitHub Actions.

## Разработка
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
python tools/package.py

TypeScript 5.8.2 используется для боевого ядра. Интеграционный клиент и Canvas2D-рендер — JavaScript, их синтаксис и запуск проверяются отдельно. npm run build пересоздаёт runtime/ и автономный PLAY.html. После правок исходников всегда пересобирать.

## Вторая итерация
Одна прежняя комната, один прежний тип противника; покой, дыхание и ходьба; смешанные трёхударные серии отдельных нажатий; реакция и смерть; контактные искры; освещающий веер 160 градусов, 5.3 клетки, 2.5 секунды; жизнь-лампа; смерть/повтор; прежние ASCII-орнаменты меню с добавленным движущимся пламенем.

WASD/стрелки — движение; ЛКМ — лёгкий удар; ПКМ — тяжёлый; E/средняя кнопка — веер; Esc — пауза. HEALTH и LAMP отображают один запас жизни; отдельного HP нет.

Казнь, рывок, лечение, чекпоинты, сохранения, новые карты/типы врагов и установщик не входят.

## Изменения рендера
Canvas2D согласован пользователем. Цвет и освещение вычисляются на сетке 196x140; видимое изображение выводится только различимыми ASCII-глифами. Точного попиксельного совпадения со старым WebGL нет. Геометрия героя и комнаты проверяются по SHA-256. Исправлено отражение мирового преобразования героя; сам vendor-файл не изменён.

## Предварительные правила
DRAFT_RULES: направление к курсору при нажатии и фиксация на удар; получение урона не прерывает атаку; выход движением из последних 14% восстановления. Эти правила ещё не утверждены как окончательные. Очередь не перезаписывается спамом, серия заканчивается после третьего удара.

## Проверки и ограничения
Результаты текущей проверки находятся в docs/. Старые отчёты и прежние заявления о 38 тестах сюда не переносятся. Браузерная проверка проверяет запуск, ввод, удары, свет, паузу, смерть, повтор и экспорт JSON. Это не гарантирует 30 FPS на устройстве пользователя. SAVE REPORT сохраняет реальные локальные замеры; GPU time не выдаётся за CPU time.
